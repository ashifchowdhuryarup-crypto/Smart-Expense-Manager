# Smart Expense Manager

Responsive React + TypeScript finance tracker for desktop and mobile.

## Features
- Income and expense CRUD
- Dashboard totals and charts
- Monthly category budgets
- Savings goals and contributions
- Search/filter transactions
- CSV export
- Dark/light theme
- Browser localStorage persistence
- BDT currency formatting
- Responsive layout

## Run locally
1. Install Node.js 20+
2. Extract this project
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL printed by Vite

## Build
`npm run build`

## Google AI Studio
Use Google AI Studio Build mode and import/upload these files if supported, or paste the source files into its project editor. Ask it to preserve the existing functionality while adding Firebase Auth + Firestore sync.

## Important
This version stores data locally in each browser. It does not yet provide cross-device account sync. Firebase requires your own project configuration and security rules.
